# Лео — подключение ИИ

Лео доступен с любого экрана. Четыре готовые подсказки объясняют текущий план, дневник и прогресс локально. История разговора хранится только в памяти приложения и сбрасывается при смене аккаунта или перезагрузке.

С согласия владельца приложения добавлено серверное подключение OpenAI Responses API. Для свободного вопроса пользователь приложения подтверждает отправку вопроса, последних восьми сообщений и краткого контекста целей, областей внимания, ограничений, выбранных упражнений и счётчиков активности. Имя, почта, видео и комментарии дневника автоматически не добавляются. Личные данные, введённые в самом вопросе, будут отправлены вместе с ним.

Сервер проверяет авторизацию, согласие, размер вопроса и роли сообщений. Контекст собирается из серверного плана; контекст, переданный браузером, не используется. Лимит — шесть запросов за минуту на пользователя в каждом процессе сервера. При масштабировании потребуется общий лимитер. Модель не получает инструменты, доступ к изменениям БД или возможность отменять ограничения. Ответы являются текстом и могут содержать ошибки.

## Настройка

В существующий файл `.env.local` добавьте, сохранив настройки Supabase:

```dotenv
OPENAI_API_KEY=ваш_секретный_ключ
OPENAI_MODEL=gpt-4.1-mini
```

Ключ вводится локально, не в чат, не в исходники и не в переменные с префиксом `VITE_`. Модель можно заменить на доступную вашему API-проекту. Перезапустите `npm run dev -- --port 5173`, затем заново откройте окно Лео. Поле модели необязательно: указанная модель используется по умолчанию.

Без ключа `/api/assistant/status` сообщает, что ИИ не подключён, и локальные подсказки продолжают работать. Серверный ключ сейчас отсутствует; реальный ответ от провайдера не проверялся.

Используется `store: false`, что отключает хранение состояния ответа Responses API; это не обещание полного отсутствия хранения у провайдера. [Официальная документация OpenAI](https://developers.openai.com/api/docs/guides/migrate-to-responses).

Проверки: lint, typecheck, сборка и 41 unit-тест прошли. Проверены отсутствие отправки без согласия, авторизация, очистка контекста от свободных комментариев, игнорирование подменённого браузером контекста и обработка ответа провайдера на заглушке. Это не клиническая проверка и не реальный запрос в OpenAI.
